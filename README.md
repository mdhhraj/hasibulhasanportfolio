# Hasibul Hasan - Static Website

This is a static HTML/CSS/JavaScript export of the WordPress site.

## Deploy
- Upload the contents of this folder to a GitHub repository.
- For GitHub Pages, select **Deploy from a branch**, choose `main` and `/ (root)`.
- For Cloudflare Pages, connect the repository and leave the build command empty; set output directory to `/`.

No WordPress login, PHP, or database is required.

## Important
The original WordPress database and backup are not included in this repository. Media files are copied into `assets/uploads/`.
